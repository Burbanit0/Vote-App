## Two things to read carefully

- **Agreement is 100% everywhere, which is less impressive than it looks.** A `vote_cast` batch that
  exhausts its retries falls back to `simple_rules.build_ranking` — the very function agreement is
  measured against. Those ballots agree by construction. The 5 first-attempt failures per arm are
  the same three citizens (69, 70, 71) sending `blank=1` with a ranking, the shape S1.2's grammar
  removes.
- **The failure count is identical across arms, to the case.** 5/34 in all four, on the same
  citizens. With greedy decoding and the same prompts that is plausible — batching changes
  scheduling, not the argmax — but it is also what a metric computed from a shared artefact would
  look like, and this run cannot tell those two apart. Worth one look if the sweep is ever repeated.

## What is not answered

- The FP8 KV cache arm, and therefore S2.1's actual comparison.
- Which worker count to run production at. The sweep says 12 is safe on these measures at
  population 100 for a year; a p500 run over 8 years is a different memory profile, and nothing here
  measures it.
